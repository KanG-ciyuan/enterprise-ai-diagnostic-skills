# Enterprise AI interview platform V0.2 — internal development baseline

Date: 2026-10-31

Acceptance: **conditional_pass — internal synthetic rehearsal only**

Baseline branch: `baseline/v0.2-internal-2026-10-31`

This snapshot preserves the application WIP and its existing commit history. It
does not change the independently versioned Skill packages or create a stable
production release. The application and the Skills are not runtime-integrated.

## 验收边界

**有条件通过，仅限内部合成演练。发布后事实／材料主动变更的页面恢复未验证；生产环境与真实企业试点尚未验证。**

现有受支持流程的验收证据包含员工访谈、人工确认、具名核验与独立双核、
等待补证恢复、诊断建议、内容审核、事实引用核验、发布、负责人退回修订和决策。
各轮证据分别包含本地运行时测试、合成业务页面操作及少量真实 DeepSeek 调用；
不能把自动化检查通过等同于完整生产业务通过。

发布后的已确认事实重新定级及既有材料主动替换，缺少普通用户可操作的完整页面入口。
后台失效／恢复与版本链有定向回归，但没有完成对应的浏览器端到端验证。
等待补证恢复、内容修改后重新审核均不能替代这一能力。若真实试点依赖它，必须另行
定义受支持入口、完成实现及验收后再准入；本基线没有为验收临时增加功能。

## 本基线包含的成果

- 员工同维度补充回答、修正口径和明确未知项的服务端历史投影与待核实交接；
  保留员工陈述 E3、原话来源、人工判定和证据边界。
- 访谈重复追问与收口规则、调用失败或额度暂停时的输入保留，以及现有 12 次额度门禁。
- 超过显示上限的推断仍可逐条人工判定；长回答引用、推断有效状态与流程卡展示修复。
- 两种补证顺序、具名首核、独立双核、证据资格、版本与权限守卫。
- 诊断建议及迁移 `0014_decision_packet_suggestions.sql`，连同迁移锁和生成的 schema 产物。
- DeepSeek 诊断专用请求明确关闭 thinking，保留 1200 输出预算、超时、单请求及空输出拒绝，
  新增截断输出拒绝；没有把 reasoning 当正式建议，没有改变员工访谈调用适配。
- G14 规范卡夹具、精确拒绝码及零副作用断言；最新正式版本与角色待办筛选，
  不再把已退回历史 v1 当作 v2 完成后的当前核验待办。

## 验证记录的范围

最终本地收尾执行了当前 CI workflow 声明的 19 条检查命令，以及 13 条额外回归，
全部成功。重点结果包括 G14 17/17、诊断适配 10/10、ROUND3 19/19、数据库状态矩阵
44/44，以及 Skills 本地检查 8 组 201 项。CI workflow 见
[local-checks.yml](../../.github/workflows/local-checks.yml)。

同步前沿用的真实诊断复验共 3 次 DeepSeek 调用，得到新的最终 JSON；发布、退回修订、
内容审核失效恢复和负责人决策有合成业务页面记录。最后一次收尾及本次 GitHub 同步
均未新增真实模型调用。后续运行的 CI 仅证明相应自动检查，以目标提交的实际结果为准。

回归夹具中的原始访谈和模型输出来自合成业务场景；测试中的固定凭据、Cookie 和
会话标记用于隔离测试或演示，不是可用的真实账号凭据。运行数据库、浏览器登录状态、
本地模型配置、私有验收输出和缓存不属于本基线。完整的本机访谈／截图证据包没有作为
公开运行数据上传。

## 已知限制

- 发布后依据主动变更的普通用户页面恢复未验证，见上述验收边界。
- 额外重复登录复验曾受既有每账号每天最多 3 次验证链接限制；没有清记录绕过。
- 模型建议仍需人工判断、约束和审核；没有量化收益依据，不能直接自动执行审批或业务操作。
- 生产身份与通知、生产 D1、真实企业数据、并发负载、部署和真实业务收益尚未验证。

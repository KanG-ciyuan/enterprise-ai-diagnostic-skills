# 企业工作摸排

面向普通企业员工，通过逐题访谈梳理一项具体工作，生成由员工确认、证据状态清晰的工作流程卡。

## 你可以直接这样说

安装后可以直接说：

- “使用企业工作摸排 Skill，帮我梳理一项日常工作。”
- “我是销售运营，请梳理我每周制作复盘报告的工作流程。”
- “根据我的回答和这份 SOP 生成工作流程确认卡。”

Agent 每次只问一个问题。员工确认流程后，输出简洁流程图、结构化流程步骤、证据状态和待确认事项。

## 边界

- 一次只摸排一名员工的一项具体工作。
- 不做部门或全企业诊断。
- 不向员工输出 AI、RPA、Agent 或其他技术改造建议。
- 不估算未经测量的降本增效。
- 不自动上传、通知、修改业务系统或联系其他人员。
- 员工口述只代表该员工的陈述，不自动视为企业事实。

## 本地验证

```bash
python3 -m unittest discover -s enterprise-workflow-mapping/tests -v
```


## 本地安装

验证通过后，将整个 `enterprise-workflow-mapping` 目录复制到当前 Agent 的个人 Skills 目录。Codex 默认目录为 `~/.codex/skills/enterprise-workflow-mapping`。当前版本没有可用的公共安装命令；未来发布后再提供 `npx skills add` 命令。

## Troubleshooting

- 如果 Agent 一次显示整套问题，要求它按 Skill 约定每次只问一个问题。
- 如果员工描述过于笼统，先把“整理、处理、审核”等词拆成可观察的具体操作。
- 如果输出出现 AI、RPA 或 Agent 建议，说明越过了员工侧边界，应删除建议并只保留工作事实。
- 如果只有员工口述、没有材料，流程卡可以继续生成，但必须标记为 `E3 员工口述，待核实`。

# 企业材料分析 Skill

把企业授权提供的流程卡、会议纪要、录音转写、SOP、Excel、截图、表单、PDF、系统记录和样本，整理成改造方可继续使用的证据包。

它回答的是：

- 每项材料能证明什么，不能证明什么；
- 不同岗位和不同材料哪里一致、哪里冲突；
- 哪些数量只是口述估计；
- 哪些是制度要求但未证明实际执行；
- 下一步最少还需要向谁、从什么系统获取什么证据。

它不负责员工访谈，也不负责决定使用工作流、RPA、AI 或 Agent。

## 常见用法

```text
使用企业材料分析 Skill，分析这些流程卡、会议转写和 ERP 样本，输出证据账本、冲突和最小补证清单，不要给技术方案。
```

你可以直接这样说：

- “找出这份 SOP 和员工实际做法之间的冲突。”
- “核验多份岗位流程卡的交接说法，列出最少还要补什么材料。”
- “分析录音转写、Excel 和截图，但不要给技术方案。”

## Troubleshooting / 常见问题

- **材料打不开：** 在材料清单中标记不可读，并继续分析其他材料；禁止猜测内容。
- **只有员工口述：** 保持 E3，输出最小补证请求，不升级为企业事实。
- **SOP 与实际说法冲突：** 同时保留 E4 规定和 E3/E1 实际证据，建立制度实践差异。
- **用户要求直接选技术：** 停止在证据交接，由后续企业 AI 应用诊断 Skill 处理。

## 输出

- 材料清单；
- 原子证据账本；
- 流程节点与来源映射；
- 一致、冲突、制度与实践差异；
- 覆盖缺口和无法读取的材料；
- 最小补证请求；
- 供企业 AI 应用诊断 Skill 使用的交接块。

## 边界

- 只读取用户授权且放入范围的材料；
- 不修改原文件，不连接生产系统，不对外发送；
- 员工确认卡仍属于员工陈述，不自动变成企业事实；
- 不输出未经证据支持的收益、技术路线或实施承诺。

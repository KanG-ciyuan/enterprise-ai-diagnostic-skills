# 制造企业紧急采购 AI 应用诊断模拟

这是一个完全虚构、脱敏的端到端测试，不代表真实企业事实或已实现的软件系统。

## 测试链路

1. 困难员工接受逐题访谈，Agent 生成并让员工确认岗位工作流程卡；
2. 生产计划、采购、仓库和财务四张确认卡进入项目诊断方内部工作区；
3. 诊断方先合并对象与交接，再提出跨角色质疑，不覆盖原始确认卡；
4. 在证据等级和缺口可见的前提下，形成内部诊断与企业负责人沟通版；
5. 输出一份可展开查看证据、矛盾、路线和试点标准的可视化档案。

## 证据声明

- 所有人物、数量和流程均为模拟；
- `员工确认` 只表示模拟角色确认 Agent 对其口述的转述，不代表真实运行证据；
- 技术路线是诊断演示，不是采购承诺或 ROI 承诺；
- 独立模型困难访谈运行因本机提供方认证失败而未通过运行门，当前材料属于可审核的受控模拟。

## Reading note

The repository's synthetic cases live in [`simulations/`](../simulations/) and are
marked `E5`. This directory is different: it holds cases built from **real work**,
which is why they carry their own, stricter disclosure and evidence statements.

Every page here separates what it can support from what it cannot. If a page
claims less than you expected, that is the method working, not the page being
unfinished.
